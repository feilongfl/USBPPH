USB 协议说明

1. 连接方式

USB 模式使用浏览器 WebUSB API。页面通过 navigator.usb.requestDevice() 查找 VID=0x1209、PID=0x0034 的 USBPPH 设备。

通道控制命令走 EP0 vendor request，不依赖 CDC 串口。WebUSB 必须运行在 https:// 或 localhost 安全上下文中。

2. 通道编号

  • wIndex = 0：Port 1 / P1.5
  • wIndex = 1：Port 2 / P1.6
  • wIndex = 2：Port 3 / P1.7

页面显示 Port 1/2/3，底层 USB 协议使用 channel 0/1/2。

3. GPIO_WRITE：设置通道状态

字段 值 说明
bmRequestType 0x40 Vendor / Host-to-device / Device recipient
bRequest 0x30 USBPPH_VENDOR_GPIO_WRITE
wIndex 0, 1, 2 通道编号。0=Port1，1=Port2，2=Port3
wValue 0, 1, 3 0=OFF，1=ON，3=TOGGLE
wLength 0 无数据阶段

4. GPIO_READ：读取通道状态

字段 值 说明
bmRequestType 0xC0 Vendor / Device-to-host / Device recipient
bRequest 0x31 USBPPH_VENDOR_GPIO_READ
wIndex 0, 1, 2 通道编号
wValue 0 忽略
wLength 1 返回 1 字节：0=OFF，1=ON

5. WebUSB / Microsoft OS 2.0 描述符请求

用途 字段 值 说明
WebUSB URL bRequest 0x22 WEBUSB_VENDOR_CODE
WebUSB URL wValue 0x0001 Landing Page index
WebUSB URL wIndex 0x0002 WEBUSB_GET_URL
Microsoft OS 2.0 bRequest 0x21 MS_OS_20_VENDOR_CODE
Microsoft OS 2.0 wIndex 0x0007 MS_OS_20_DESC_INDEX

6. USB 控制示例

// Port 1 ON
await device.controlTransferOut({
  requestType: "vendor",
  recipient: "device",
  request: 0x30,
  value: 1,
  index: 0
});

// Port 1 READ
const r = await device.controlTransferIn({
  requestType: "vendor",
  recipient: "device",
  request: 0x31,
  value: 0,
  index: 0
}, 1);

const state = r.data.getUint8(0); // 0=OFF, 1=ON

命令终端

串口协议说明

1. 连接方式

串口模式使用浏览器 Web Serial API。设备固件枚举为 USB CDC ACM 虚拟串口。 Windows 下表现为 COMx，Linux 下通常为 /dev/ttyACM*，macOS 下通常为 /dev/cu.usbmodem*。

页面默认使用 115200 8N1 打开串口。USB CDC 的波特率参数主要用于主机兼容性； 实际 USB 传输不依赖传统 UART 波特率。

2. 帧格式

  • 命令使用 ASCII 文本。
  • 每条命令以 \n 或 \r\n 结束。
  • 命令不区分大小写。
  • 正常控制命令通常返回 OK。
  • 查询命令返回文本值，例如 1、0,1,0 或 *IDN? 的设备识别字符串。
  • 错误命令返回 ERR，详细错误可通过 SYST:ERR? 查询。

3. IEEE-488.2 基础命令

命令 类型 返回 说明
*IDN? 查询 feilong,USBPPH,<serial>,<version> 读取制造商、产品名、芯片序列号和固件版本。
*RST 控制 OK 复位逻辑输出状态，所有通道关闭。
*CLS 控制 OK 清除错误状态。
*OPC? 查询 1 Operation Complete 查询。当前实现中立即返回 1。
SYST:ERR? 查询 +0,"No error" 或错误信息 查询并弹出最近一次错误状态。

4. OUTP 通道命令

命令 返回 说明
OUTP? 0,1,0 读取全部通道状态，顺序为 Port1,Port2,Port3。
OUTP:ALL? 0,1,0 同 OUTP?。
OUTP:ALL ON OK 打开全部通道。
OUTP:ALL OFF OK 关闭全部通道。
OUTP:ALL TOG OK 翻转全部通道状态。
OUTP1? 0 或 1 读取 Port 1 状态。
OUTP1 ON OK 打开 Port 1。
OUTP2 OFF OK 关闭 Port 2。
OUTP3 TOG OK 翻转 Port 3。
OUTP 1,ON OK 兼容带空格和逗号的写法。

5. ROUT 路由命令

命令 返回 说明
ROUT:CLOS (@1) OK 闭合 Port 1。等效于 OUTP1 ON。
ROUT:OPEN (@1) OK 断开 Port 1。等效于 OUTP1 OFF。
ROUT:CLOS? (@1) 0 或 1 查询 Port 1 是否闭合。

7. 状态与物理电平

页面、USB 协议和串口协议显示的是逻辑状态： 1 表示逻辑 ON，0 表示逻辑 OFF。

硬件为 active-low：逻辑 ON 时 GPIO 输出低电平；逻辑 OFF 时 GPIO 输出高电平。 因此不要用 GPIO 物理电平直接理解页面上的 ON/OFF。
