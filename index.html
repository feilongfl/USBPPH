设备使用说明

1. 浏览器要求

  • 网页需要通过 HTTPS 打开，GitHub Pages 满足该条件。
  • WebUSB 用于直接控制通道开关。
  • Web Serial 用于通过 CDC 串口发送 SCPI 命令。
  • 部分移动端浏览器可能不支持 WebUSB 或 Web Serial。

2. 基本操作

  • 点击「连接 WebUSB」授权 USBPPH 设备。
  • 点击「刷新状态」读取三个通道当前状态。
  • 点击每个通道的 ON / OFF / TOGGLE 控制输出。
  • 点击「连接串口」后可使用命令终端。

3. 常用命令

  • *IDN?：读取设备型号、序列号、固件版本。
  • OUTP:ALL?：读取全部通道状态。
  • OUTP1 ON：打开 1 通道。
  • OUTP2 OFF：关闭 2 通道。
  • ROUT:CLOS (@1)：闭合 1 通道。
  • ROUT:OPEN (@1)：断开 1 通道。

4. 通道语义

页面显示的是逻辑状态，不是 GPIO 物理电平。固件内部为 active-low： 逻辑 ON 对应 GPIO 低电平，逻辑 OFF 对应 GPIO 高电平。

5. Windows COM 号

固件通过芯片唯一 ID 生成稳定 USB 序列号。同一台 Windows 电脑通常会为同一个序列号保持相同 COM 号。 若要强制指定 COM 号，需要 Windows 侧设备管理器或脚本处理。

6. 安全提示

控制外接设备时，先确认电源容量、接线方向和负载电流。调试未知设备时建议先关闭所有通道，再逐个打开。
